### 研究與需求蒐集
我梳理了診所的真實限制條件：除了名稱之外沒有任何現成的品牌資產、病患普遍偏好 WhatsApp 而非電子郵件，以及一段家族故事——自 1952 年起傳承三代——以此作為建立信任策略的核心。

### 資料架構
我將網站架構設計為使用錨點導航的單頁式網站，串接了 schema.org 的 Organization 結構化標記與 Open Graph 中繼資料，以確保網站在外部平台上的呈現方式，並規劃了從表單到收件匣的流程：WPForms → 透過 Gmail API 進行驗證的 SMTP → 診所的真實收件匣。

### UX 設計與原型製作
我圍繞著診所藍到藍綠色漸層的牙齒標誌，建構出整套視覺系統，讓色調保持冷靜且具臨床感，而非採用較溫暖、常見的牙醫品牌形象。

### 前端開發
我使用 WordPress／Elementor 建構網站，並手寫 CSS 打造客製化設計系統，響應式設計支援至 640px 寬度，並將正式上線的圖像素材——標誌組合與主視覺攝影——優化並以 WebP 格式提供。

### 測試與優化
我反覆執行 Lighthouse 稽核，並以實證方式修正每一項被標記的問題：依相對亮度公式計算 WCAG 對比度、修正標題階層、加入結構化資料，並在每次修改後重新驗證。
