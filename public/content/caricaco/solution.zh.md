我用 Astro 與 Tailwind CSS v4 從零重建了這個登陸頁——這是一套靜態、快速的技術堆疊，讓一個沒有全職開發者的基金會真正能夠自行維護，完全取代了那套無人維護的 Bootstrap／jQuery 範本。故障的 PHP 聯絡表單處理程式，改以內嵌的 Google 表單流程取代：不需要維護任何後端，即使申請者是用共用電腦或行動數據填寫，訊息也能可靠地送達團隊的收件匣。

我保留了這個計畫既有的品牌識別——由海軍藍漸層至紫色、並以溫暖的橘色作為點綴，標題使用 Montserrat、內文使用 Nunito——但將其套用得更加一致：統一的按鈕樣式、統一的字級系統，不再有同一個 CTA 的四種不同呈現方式。考量到多數申請者是透過 3G／4G 行動網路使用手機瀏覽，低速連線下的效能與視覺上的精緻度獲得了同等的優先順序。

**在這裡，無障礙設計不只是打勾了事** — 一個以對抗不平等為使命的基金會，不能在能力上排除任何人，否則便失去說服力。我依照 WCAG 2.1 AA 標準建置並稽核了整個網站，同時落實了真正的 SEO 基礎：準確的 meta title 與描述，以及 schema.org 的 `Organization` 和 `EducationEvent` 結構化資料，取代了原本 Google 一直在索引的那個「Free HTML Templates」字面占位文字。
