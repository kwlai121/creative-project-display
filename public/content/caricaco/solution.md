I rebuilt the landing page from the ground up on Astro and Tailwind CSS v4 — a static, fast stack a foundation with no full-time developer can actually maintain, replacing the unmaintained Bootstrap/jQuery template entirely. The broken PHP contact handler was replaced with an embedded Google Forms flow: zero backend to maintain, and reliable delivery to the team's inbox even for applicants filling it out on shared computers or mobile data.

I kept the program's existing brand — a navy-to-purple gradient anchored by a warm orange accent, Montserrat for display type and Nunito for body text — but applied it consistently: one button style, one type scale, no more four different renderings of the same CTA. Given that most applicants arrive on mobile over 3G/4G, performance on low-end connections got the same priority as visual polish.

**Accessibility wasn't a checkbox here** — a foundation whose mission is fighting inequality can't credibly exclude people by ability. I built and audited the site against WCAG 2.1 AA, alongside real SEO fundamentals: an accurate meta title and description, and schema.org `Organization` and `EducationEvent` structured data, replacing the literal "Free HTML Templates" placeholder that Google had been indexing.
