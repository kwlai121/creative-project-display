Fundación Caricaco 的青年創業計畫「Academia Caricaco」，原本架設在一套免費 HTML 範本上——Bootstrap 5 加 jQuery，自上線後從未維護過。真正危險的是聯絡表單：它會將資料送往一支早已不存在的 PHP 腳本，因此任何申請者只要輸入訊息而不是點擊主要按鈕，訊息就會被無聲地遺失，沒有錯誤提示，也沒有確認訊息。對一個有嚴格申請截止日期的計畫來說，這不只是個小 bug——而是一個看不見的漏洞，正悄悄流失基金會存在的意義所要觸及的那群人。

### 主要挑戰

- **會說謊的表單** — 聯絡表單看起來能運作，但只要不是透過主要 CTA 送出，每一則訊息都會被靜默丟棄，申請者與基金會雙方都收不到任何錯誤提示。
- **在搜尋中隱形** — 網站的 `<title>` 與 meta description 仍寫著「Free HTML Templates」。一個致力對抗不平等的基金會，在 Google 眼中卻只是一個沒有品牌的範本示範頁。
- **執行方式削弱了自身的訊息** — 主要的 CTA 按鈕（「Aplicación Gratuita」）在頁面上出現了四次，卻用了三種不同字級與兩種不同字體，而一個關鍵標題在特定筆電螢幕寬度下會完全消失。

這個計畫的申請者是 18 至 29 歲、居住在高失業率都會及城郊地區的年輕人，多數是透過社群媒體活動而來，那些活動承諾著看似認真的機會——與 Platzi 的合作、5,000 美元獎金、真正的導師輔導。他們抵達的登陸頁卻完全撐不起這個承諾，而且沒有任何錯誤訊息告訴他們哪裡出了問題。他們只是沒有完成申請，也沒有再回來。
